### 🐟 AquaGuardian — IoT Fish Pond Management System
`Raspberry Pi 4` `Python` `Flask` `Random Forest ML` `GSM` `ThingSpeak`

An end-to-end aquaculture automation system combining real-time IoT sensing,
machine learning water-quality classification, and multi-channel remote alerting.

- **7-Parameter Sensing** — pH, Temperature, EC, Turbidity, and N/P/K via 7-in-1 NPK sensor
- **ML Water Quality Classifier** — Random Forest model rates water as Excellent / Good / Poor and triggers smart alerts
- **Automated Actuation** — Threshold & ML-driven control of aeration and circulation pumps
- **Remote Alerts** — GSM/SMS via SIM800C for off-grid notifications; LED & buzzer local indicators
- **Cloud Dashboard** — Flask web app (Render + Neon.tech) with live telemetry and historical reporting via ThingSpeak
- **Local Interface** — I2C 16×2 LCD for real-time on-site parameter readouts
